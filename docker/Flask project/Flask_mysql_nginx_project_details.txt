Step 1: app/app.py
------------------
from flask import Flask, jsonify
import mysql.connector
import os

app = Flask(__name__)

@app.route('/')
def hello():
    try:
        conn = mysql.connector.connect(
            host=os.getenv("MYSQL_HOST", "db"),
            user=os.getenv("MYSQL_USER", "root"),
            password=os.getenv("MYSQL_PASSWORD", "secretpass"),
            database=os.getenv("MYSQL_DB", "testdb")
        )
        cursor = conn.cursor()
        cursor.execute("SELECT 'Hello from MySQL!'")
        result = cursor.fetchone()
        cursor.close()
        conn.close()
        return result[0]
    except Exception as e:
        return f"Error: {e}"

@app.route('/health')
def health():
    return jsonify({"status": "ok"})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

Step 3: app/Dockerfile
----------------------
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 5000
CMD ["python", "app.py"]


Step 4: nginx/default.conf
--------------------------
server {
    listen 80;

    location / {
        proxy_pass http://web:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}


Step 5: docker-compose.yml
--------------------------
version: "3.9"

services:
  web:
    build: ./app
    container_name: flask_app
    environment:
      - MYSQL_HOST=db
      - MYSQL_USER=root
      - MYSQL_PASSWORD=secretpass
      - MYSQL_DB=testdb
    depends_on:
      - db
    expose:
      - "5000"

  nginx:
    image: nginx:latest
    container_name: nginx_proxy
    ports:
      - "8080:80"
    volumes:
      - ./nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - web

  db:
    image: mysql:5.7
    container_name: mysql_db
    environment:
      MYSQL_ROOT_PASSWORD: secretpass
      MYSQL_DATABASE: testdb
    volumes:
      - db_data:/var/lib/mysql

volumes:
  db_data:


Step 6: Run the Project
-----------------------
docker-compose up -d --build
docker-compose ps

Open browser: http://localhost:8080
Output: Hello from MySQL!

Health endpoint: http://localhost:8080/health


Step 7: Flow
-------------
Browser → Nginx (port 8080) → Flask (port 5000) → MySQL (port 3306)

Step 9: Optional AWS EC2 Setup (For Learning)
---------------------------------------------
1. Launch EC2 (Ubuntu)
2. Install Docker + Docker Compose
3. Copy this project to EC2 (scp -r myproject/ ec2-user@<public-ip>:/home/ec2-user/)
4. Run docker-compose up -d --build
5. Open port 8080 in Security Group
6. Access http://<your-ec2-public-ip>:8080

GoDaddy Domain Setup:
- Add A record:
  - Name: @
  - Value: EC2 public IP
  - TTL: 600
