
JENKINS PLUGINS — COMPLETE GUIDE
=================================================

INTRODUCTION
-------------
Jenkins itself is a lightweight automation server.  
Its real power comes from **plugins**, which add functionality for SCM integration, build tools, UI features, reporting, and more.

✅ Jenkins core = basic automation engine  
✅ Plugins = add features, integrations, and capabilities

Plugins are managed via:
    Manage Jenkins → Manage Plugins

They can be installed from:
- Jenkins Plugin Manager (default)
- Custom update centers
- .hpi or .jpi plugin files manually uploaded

------------------------------------------------------------
PLUGIN TYPES
------------------------------------------------------------
Plugins can be grouped by purpose:

1️⃣ **Source Code Management (SCM)**
   - Integrate with Git, GitHub, Bitbucket, GitLab, SVN, etc.

2️⃣ **Build Tools**
   - Add support for Maven, Gradle, NodeJS, Docker, etc.

3️⃣ **Pipeline and CI/CD**
   - Extend Jenkins pipeline capabilities and visualization.

4️⃣ **Notifications and Reporting**
   - Email, Slack, JUnit, TestNG, HTML reports, etc.

5️⃣ **Cloud and Container Integrations**
   - AWS, Kubernetes, Docker, Azure, GCP, etc.

6️⃣ **Security and Credentials**
   - Manage users, secrets, and authentication mechanisms.

7️⃣ **UI Enhancements**
   - Improve dashboard visualization and job monitoring.

------------------------------------------------------------
PLUGIN MANAGEMENT
------------------------------------------------------------
To install plugins:

1. Go to **Manage Jenkins → Manage Plugins**
2. Under **Available** tab → search by name
3. Click **Install without restart**
4. Or use **Advanced** tab → upload a `.hpi` or `.jpi` plugin manually

To list installed plugins:
- Navigate to **Installed** tab
- Or run from Jenkins CLI:
  java -jar jenkins-cli.jar -s http://localhost:8080/ list-plugins

BUILD TIMESTAMP PLUGIN DETAILS
------------------------------------------------------------
- Adds build timestamps as environment variables.
- Helps include build time in artifact names, logs, or reports.

Common environment variables:
  ${BUILD_TIMESTAMP} — formatted date/time string
  ${BUILD_ID} — build number or timestamp-based ID

Example usage in pipeline:
pipeline {
    agent any
    stages {
        stage('Build with Timestamp') {
            steps {
                script {
                    echo "Build started at: ${env.BUILD_TIMESTAMP}"
                    sh "mvn clean package -Dbuild.time=${env.BUILD_TIMESTAMP}"
                }
            }
        }
    }
}

Setup steps:
1. Install plugin: Manage Jenkins → Manage Plugins → Available → "Build Timestamp"
2. Restart Jenkins if needed.
3. Configure timestamp format under: Manage Jenkins → Configure System → Build Timestamp.

PIPELINE EXAMPLE USING SOME PLUGINS
------------------------------------------------------------
pipeline {
    agent any
    tools {
        jdk 'jdk17'
        maven 'maven3'
    }
    stages {
        stage('Checkout') {
            steps {
                git branch: 'main', url: 'https://github.com/example/myapp.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean install'
            }
        }
        stage('Code Quality') {
            steps {
                withSonarQubeEnv('SonarQubeServer') {
                    sh 'mvn sonar:sonar'
                }
            }
        }
        stage('Test Reports') {
            steps {
                junit '**/target/surefire-reports/*.xml'
            }
        }
        stage('Notify') {
            steps {
                slackSend(channel: '#ci-cd', message: "Build completed for ${env.JOB_NAME}")
            }
        }
    }
}

------------------------------------------------------------
PLUGIN MANAGEMENT VIA CLI AND GROOVY
------------------------------------------------------------

CLI Examples:
--------------
# List all plugins
java -jar jenkins-cli.jar -s http://localhost:8080/ list-plugins

# Install plugin by name
java -jar jenkins-cli.jar -s http://localhost:8080/ install-plugin git

# Update all plugins
java -jar jenkins-cli.jar -s http://localhost:8080/ safe-restart

# Check plugin versions
java -jar jenkins-cli.jar -s http://localhost:8080/ list-plugins | grep outdated

Groovy Script Example (in Script Console):
-------------------------------------------
Jenkins.instance.pluginManager.plugins.each {
    println "${it.getShortName()} (${it.getVersion()})"
}

To install plugin programmatically:
def instance = Jenkins.getInstance()
def pm = instance.getPluginManager()
def uc = instance.getUpdateCenter()
def plugin = uc.getPlugin("git")
plugin.deploy()
instance.save()
