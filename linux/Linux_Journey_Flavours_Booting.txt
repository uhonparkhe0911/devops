Linux Journey, Flavours, and Booting Process - Summary
------------------------------------------------------------

1. Linux Journey
------------------------------------------------------------
- Linux is an open-source Unix-like OS created by Linus Torvalds in 1991.
- Integrated with GNU tools to form complete OS (GNU/Linux).
- Key milestones:
  - 1991: Linux Kernel released
  - 1992-1994: Full GNU/Linux OS
  - 2000s: Powers servers and enterprise systems
  - 2010s: Foundation for DevOps, Cloud, Containers
  - Today: Core of cloud computing, SRE automation, and Kubernetes nodes
- Advantages for DevOps/SRE:
  - Stability and security
  - Open source and customizable
  - Powerful command-line tools
  - Compatible with cloud and containers
  - Resource-efficient

2. Linux Flavours (Distributions)
------------------------------------------------------------
- A Linux Distribution = Linux Kernel + GNU Tools + Package Manager + GUI (optional)

Major Families:
| Family        | Examples                        | Package Manager   | Use Case                         |
|---------------|--------------------------------|-----------------|----------------------------------|
| Debian Family | Debian, Ubuntu, Kali Linux      | apt / dpkg      | Developer-friendly, servers, desktops |
| Red Hat Family| RHEL, CentOS, Fedora, Rocky Linux | yum / dnf / rpm | Enterprise servers, cloud         |
| SUSE Family   | openSUSE, SLES                  | zypper          | Enterprise workloads             |
| Arch Family   | Arch Linux, Manjaro              | pacman          | Lightweight, customizable       |
| Others        | Alpine, Oracle Linux, Amazon Linux | Varies        | Containers, cloud, minimal systems |

Popular in DevOps/SRE:
- Ubuntu Server, CentOS / Rocky Linux, Amazon Linux 2, Alpine Linux

3. Linux Booting Process
------------------------------------------------------------
Stages of booting:
| Step | Stage                  | Description |
|------|-----------------------|-------------|
| 1    | BIOS / UEFI           | POST, hardware check, find bootable device |
| 2    | Boot Loader (GRUB)    | Load Linux kernel into memory |
| 3    | Kernel Initialization | Initialize CPU, memory, mount root FS read-only |
| 4    | init / systemd        | Kernel executes init/systemd (PID 1) |
| 5    | Runlevel / Targets    | systemd runs targets (multi-user/graphical) |
| 6    | Service Startup       | Background daemons start (network, logging, cron) |
| 7    | Login Prompt          | User login shell appears (console or GUI) |

Modern systemd boot flow:
Power On → BIOS/UEFI → GRUB → Kernel → initramfs → systemd → Targets → User Login

4. Key Linux Concepts for DevOps/SRE
------------------------------------------------------------
- Filesystem Hierarchy: /etc, /var, /usr, /home, /opt, /tmp
- Shells: Bash, Zsh, Fish
- Process Management: ps, top, kill, systemctl
- Package Management: apt, yum, dnf, zypper
- Networking: ifconfig, ip, netstat, ss, ping
- Logs: /var/log/, journalctl
- User Management: useradd, passwd, sudo, chmod, chown
